# Written report

The submitted report is kept in this local directory as `Final Report.docx`, with a PDF export, `Final Report.pdf`, made for convenience. Both are excluded from Git by the repository's `.gitignore` because the cover page shows a student number and the supervisor's name.

To publish the report, first decide whether to redact the cover page, then remove the `reports/*.pdf` line from `.gitignore` and commit the PDF. Hashes for both files are recorded in [source-artifacts.json](../docs/source-artifacts.json).

The report's abstract describes a strong prompt effect; the [README](../README.md#reading-the-results) explains why the stored outputs support a more limited reading.
